# تقرير المخازن العامة 2026 – الدقهلية للدواجن

React + TypeScript + Vite، بيسحب الداتا من Google Sheets عن طريق Apps Script ويتحدّث تلقائياً كل 60 ثانية.

## 1) Apps Script
1. افتح ملف Google Sheet بتاع المخازن (لازم يكون فيه شيتات: الصرف، الاضافة، طلب الشراء، الشاشة الرئيسية، المرتجع، التسوية بالاضافة، التسوية بالخصم، التحويلات).
2. Extensions > Apps Script، الصق محتوى `gas/Code.gs`.
3. شغّل الدالة `testRun` مرة واحدة ووافق على الصلاحيات، وبص في Logs على الأعداد.
4. Deploy > New deployment > Web app: Execute as **Me**، Who has access **Anyone** ، وانسخ الرابط.

لو ترتيب الأعمدة اتغير، عدّل الحروف في `COLS` أعلى الملف بس.

## 2) التطبيق
```
npm install
cp .env.example .env     # حط الرابط في VITE_APPS_SCRIPT_URL
npm run dev              # للتجربة
npm run build            # للنشر (مجلد dist، مثلاً على Vercel)
```
من غير رابط، التطبيق بيشتغل ببيانات تجريبية من `public/sample.json`.

## قواعد الحساب
- العدّ بعدد بنود الحركة (وحدات القياس مختلفة).
- أذون الصرف = أرقام طلب الصرف المختلفة، أذون الإضافة = أرقام الأوردر المختلفة (زي الشيت).
- تواريخ السنة الغلط (0206 / 202 / 226) بتتصحح لـ 2026، وأي تاريخ خارج 2026 أو في المستقبل بيتستبعد.
- لو غيّرت شكل الداتا زوّد `DATA_SCHEMA_VERSION` في `Code.gs` و `src/lib/useData.ts` عشان الكاش القديم يتمسح.
